# FARMER

地域の農家や農業の入り口を紹介するための道具。

FARMER は、農家の仕事、地域の農業、就農や農業体験への導線を、見やすく整理するための静的Webサイトです。

## コンセプト

農業を、遠い仕事にしない。

知らない人には見えにくい農家の仕事や地域の魅力を、写真、言葉、ステップ、紹介ページとして届けるための小さな案内所です。

## できること

- 地域の農家や農業の紹介
- 農業体験や就農への入口づくり
- 作物・圃場・地域の魅力の整理
- 公式LINEや問い合わせ先への導線づくり
- 写真や紹介文による静的ページ運用

## 利用時の注意

掲載する写真、氏名、連絡先、所在地、営業情報などは、本人や関係者の許可を得たうえで使用してください。

農業体験、就農、補助事業、農地、雇用、契約に関する判断は、必要に応じて自治体、農業委員会、関係機関、専門家に確認してください。
